# EFrame Effects

Optional EFrame extension package for reusable presentation effects.

## Contents

- `FlyAnimationSystem`: pooled fly-item sequences driven by EFrame assets and audio.
- `IconBounceEffect`: configurable icon bounce presentation component.
- `CameraShakeFx`: lightweight camera shake helper.
- Editor inspectors for fly animation and icon bounce configs/debug runners.

Runtime namespaces:

```csharp
using EFramework.Extensions.Effects;
using EFramework.Extensions.Effects.Fly;
using EFramework.Extensions.Effects.IconBounce;
```

## Dependencies

- `com.eframework.core`
- `com.unity.addressables`
- `com.unity.ugui`
