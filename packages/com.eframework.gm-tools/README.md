# EFrame GM Tools

Optional EFrame extension package for GM/debug entry UI helpers.

## Contents

- `GMButton`: corner-tap activated GM entry button that loads project-provided Addressables prefabs.

Runtime namespace:

```csharp
using EFramework.Extensions.GMTools;
```

## Dependencies

- `com.eframework.core`
- `com.unity.addressables`
- `com.unity.ugui`
