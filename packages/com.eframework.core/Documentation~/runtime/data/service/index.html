Data / Data Service

IDataService / DataManager 负责注册、批量加载保存和 App 生命周期接线。

特点和能力

Service

只做注册、查找、批量加载保存和生命周期接线。

Table

拥有业务字段、修改入口、迁移、默认值和结果解释。

Storage

只关心字节、文件、备份、序列化和底层失败。

范例

Data Service 使用位置

  • 启动流程注册表。
  • 业务逻辑通过表的公开 API 修改数据。
  • UI 和遥测读取结果对象，不依赖日志文本。

API 细节

入口用途最小记忆点
RegisterTable<T>()创建并加载表校验 Key 和 StorageKey 唯一性。
GetTable<T>()按类型获取表未注册会记录错误。
LoadAll/SaveAll批量编排不理解单张表业务语义。
Dispose()保存并释放表应用退出路径。
