Addressables

Asset 模块的重点不是“能不能加载”，而是“能不能带着生命周期和释放责任一起加载”。

EFrameWork 用 `IAssetService` 和显式 handle 包装 Addressables。你拿到资源或实例时，同时也拿到一份需要归还的责任，这样运行时缓存和释放策略才能稳定。

服务接口
`IAssetService`
实现
`AssetManager`
句柄
`AssetHandle` / `InstanceHandle`
Managed Addressables

EFrame resources are directory-owned, not manually address-owned.

Mapped directories

Put managed runtime assets under `Assets/App/Res`, project scenes under `Assets/Scenes`, and module assets under `Assets/Modules/<Name>/Res` or `Assets/Modules/<Name>/Scenes`.

Automatic sync

The editor syncs managed resources after import, move, or delete. `ResPath.Generated.cs` is generated from the directory subtrees selected in the report window.

Build preflight

Player builds run an EFrame Addressables preflight. Stale groups, addresses, labels, selected generated addresses, or stale `ResPath.Generated` fail the build before content ships.

Key APIs

关键 API 参数与返回值

`LoadAsync(string assetId)`

参数类型说明
`assetId``string`Addressables 地址或框架约定路径。建议统一来自 `ResPath` 或生成类。
返回值`UniTask>`异步结果句柄。读取资源通过 `handle.Asset`，释放通过 `handle.Dispose()`。
 
var handle = await EFrame.Current.Assets.LoadAsync<GameObject>(assetPath);
try
{
    var prefab = handle.Asset;
}
finally
{
    handle.Dispose();
}

`InstantiateAsync(string assetId, Transform parent = null)`

项说明
`parent`可选父节点。为空时直接实例化。
返回值`UniTask`，通过 `handle.GameObject` 访问实例。
额外行为实例创建后会尝试 `EFrame.Current?.InjectInto(handle.Result)`，把上下文注入给上下文感知对象。

`IsValidPathAsync(string assetId)`

用于在运行时异步验证一个路径是否在 Addressables 中有效，适合在非关键路径上做保护性检查。

Lifecycle

使用时必须记住的约束

先初始化再加载

`EFrame.Initialize()` 内部会先跑 `AssetManager.InitializeCoroutine()`。初始化失败时，后续模块会直接中断。

Handle 不是可选项

不要把 `AssetHandle` / `InstanceHandle` 当成中转值后立刻丢掉。释放责任和资源生命周期绑定在一起。

路径集中管理

资源路径应统一来自 `ResPath`、`ResPath.Generated` 或同类中心类，不要把裸字符串散落在业务逻辑里。
