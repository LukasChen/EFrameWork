Addressables + Handles

Assets 资源加载

EFrame 托管 Assets/App/Res、Assets/Scenes 和 Assets/Modules，Editor 自动同步 Addressables，业务运行时通过 ResPath 和显式 handle 访问。

服务
IAssetService
资源 id
ResPath
约束
handle 必须释放

特点和能力

托管目录

Assets/App/Res、Assets/Scenes、Assets/Modules 由 EFrame 同步 Addressables。

生成路径

ResPath 只暴露被选择的资源入口。

显式句柄

AssetHandle<T> 和 InstanceHandle 表达释放责任。

构建预检

Player build 前会检查托管 entries 和生成路径是否漂移。

范例

Procedure 预加载 + Controller 使用

  • 资源放在托管目录。
  • 通过 Addressables 同步窗口选择生成 ResPath 的目录。
  • Procedure 热路径使用 preload scope。
protected override async UniTask OnPreloadAsync(IAssetPreloadScope assets, ProcedureEnterContext context)
{
    await assets.PreloadAsync(ResPath.UI.HomeView);
}

API 细节

入口用途最小记忆点
LoadAsync<T>(assetId)加载资源并返回 AssetHandle<T>读取 handle.Asset，结束时 Dispose()。
InstantiateAsync(assetId, parent)实例化 Addressables 对象返回 InstanceHandle。
GetFromPool(assetId, parent)复用型实例化由句柄归还。
EFrame Tools/Addressables/Sync Groups And Generate ResPath同步托管目录并生成 ResPath手工修复和审查入口。
