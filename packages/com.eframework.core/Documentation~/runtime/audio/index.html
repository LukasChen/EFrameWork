Music / SFX / Mixer

Audio 基础播放

事件式音频映射和触觉反馈不再属于 Core。Core 提供 AudioManager、AudioClipAsset、Music/SFX、Mixer 音量、防抖和音乐 crossfade。

服务
IAudioService
资产
AudioClipAsset
资源
AudioResourcePaths

特点和能力

Music / SFX

统一播放入口和基础路由。

Mixer 音量

通过 Audio Bootstrap 准备 mixer 后统一控制音量。

SFX 池化与防抖

短音效播放带基础对象池和最小间隔控制。

AudioClipAsset

把多个音频片段和播放参数包装成资产。

范例

播放一个 UI 音效

  • 用 Audio Bootstrap 准备 mixer 和基础资源。
  • 短音效走 PlaySfx。
  • 复杂音频集合可包装成 AudioClipAsset。
Context.Audio.PlaySfx("Audio/UI/Click");
await Context.Audio.PlayMusicAsync("Audio/Music/Home", fadeDuration: 0.35f);

API 细节

入口用途最小记忆点
PlaySfx(assetPath)播放短音效内部带基础池化和防抖。
PlayMusicAsync(assetPath, fadeDuration)播放/切换 BGM双 AudioSource crossfade。
SetMusicVolume/SetSfxVolumeMixer 音量控制依赖 Audio Bootstrap。
PlayAudioClipAsset(...)播放包装后的音频资产适合多 clip 或参数化音频。
