Event Bus

事件系统是框架内解耦的基础，但更重要的是订阅生命周期必须跟对象生命周期对齐。

EFrame 的事件系统以结构体事件和泛型订阅为主，框架层已经内置了启动、暂停、恢复、退出和逐帧更新事件。更推荐使用 `SubscribeScoped()`，减少 UI、Controller 和短生命周期对象的泄漏风险。

服务接口
`IEventService`
核心总线
`EventBus`
事件约束

Key APIs

关键 API 参数与返回值

`Subscribe(Action handler)`

项说明
泛型约束`T : struct, IEvent`，事件保持轻量值类型。
责任调用者自己管理取消订阅，适合生命周期长且明确的对象。

`SubscribeScoped(Action handler)`

项说明
返回值`IDisposable`。释放该对象即可取消订阅。
推荐场景UI 控制器、视图、临时流程、测试工具等与对象生命周期强绑定的订阅。
 
var subscription = EFrame.Current.Events.SubscribeScoped<AppPausedEvent>(evt =>
{
    Debug.Log(evt.Duration);
});

`Dispatch(T evt)`

分发一个结构体事件。适合应用状态广播、UI 行为通知和轻量模块通信，不适合承载大型对象图或复杂异步协议。

Built-in Events

框架内置事件

`AppStartedEvent`

框架初始化完成、流程启动后广播。

`AppPausedEvent`

应用进入后台时广播，包含当前累计时长 `Duration`。

`AppResumedEvent`

应用从后台恢复时广播。

`AppQuitEvent`

应用退出前广播。

`AppUpdateEvent`

每帧广播，包含 `DeltaTime` 和 `UnscaledDeltaTime`。

`AppUpdatePerSecondEvent`

每秒广播一次，适合轻量定时刷新。
