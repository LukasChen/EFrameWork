API 细节

入口用途最小记忆点
OnBindingSetView 拿到 binding 后早于 Controller OnViewCreated。
OnViewCreated实例首次创建绑定实例级事件。
OnViewOpened每次打开成功后刷新显示状态。
OnViewClosed每次关闭开始暂停 per-open 工作。
OnViewDestroyed实例释放缓存关闭不会触发。
