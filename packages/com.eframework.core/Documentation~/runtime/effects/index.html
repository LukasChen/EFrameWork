Visual Effects

Effects 已迁入可选 `com.eframework.effects` 扩展包。

`FlyAnimationSystem`、`IconBounceEffect` 和 `CameraShake` 不再属于 `com.eframework.core`。需要这些表现能力的项目应显式安装 `com.eframework.effects`，core 只保留稳定基础设施。

Fly Effects

飞行动画系统

`FlyAnimationSystem.Play(FlySequenceRequest request)`

参数类型说明
`request.Config``FlyAnimationConfig`飞行动画配置，决定资源、路径、数量压缩和音效策略。
`request.LogicalCount``int`逻辑数量，不一定等于最终可视飞行体数量，系统会按配置压缩。
`request.StartPosition` / `TargetPosition``Vector3`起点和终点。
`request.Parent``Transform`可选父节点，适合 UI 或特定层级挂载。
返回值`FlySequenceHandle`当前播放序列的句柄，可用于后续跟踪有效性。
 
var handle = FlyAnimationSystem.Play(new FlySequenceRequest
{
    Config = coinFlyConfig,
    LogicalCount = 20,
    StartPosition = start,
    TargetPosition = target,
    Parent = uiRoot,
    OnArrive = delta => score += delta
});

`FlySequenceRequest` 还支持 `Scale`、`UseUnscaledTime`、`VisualCountOverride`、`DisposeMode`、`OnCompleted` 等参数。实际意义是把“逻辑数量”“可视表现数量”“实例释放策略”解耦，不让业务直接承担表现资源池化细节。

Config Details

`FlyAnimationConfig` 参数细节

字段类型作用
`PrefabReference``AssetReferenceGameObject`飞行体预制体入口。`HasValidAsset` 依赖它判断配置是否可播放。
`PathType``FlyPathType`路径类型，可选 `Linear`、`QuadraticBezier`、`CubicBezier`、`ScatterThenFly`。
`Duration``float`整体飞行时长，下限 0.01 秒。
`MoveProgress``AnimationCurve`控制轨迹推进节奏，不改变轨迹形状，只改变时间分布。
`ScaleOverLife``AnimationCurve`控制飞行体生命周期中的缩放倍数。
`AlphaOverLife``AnimationCurve`控制飞行体生命周期中的透明度。
`StartRandomRadius``float`起点随机偏移半径，用于让多个飞行体在起点附近散开。
`RotateSpeedDeg``float`每秒旋转角速度，0 表示不旋转。

`ScatterThenFly` 专用字段

字段说明
`ScatterDuration`散开阶段飞向随机点的时长。
`ScatterMoveProgress`散开阶段自己的移动曲线。
`ScatterHoldDuration`散开后停留时长。
`ScatterFlyControl1Offset` / `ScatterFlyControl2Offset`从散开点飞向目标点时使用的三次贝塞尔控制点偏移。

序列与音效字段

字段说明
`BaseInterval`序列发射基础间隔。
`IntervalMultiplier`根据序列进度动态调整实际发射间隔。
`MaxVisualCount`逻辑数量很大时的可视压缩上限。
`FlySoundMode` / `ArriveSoundMode`控制音效是按序列播放一次、按每个 item 播放，还是关闭。
`FlySoundAsset` / `ArriveSoundAsset`音频资源入口，优先使用 `AudioClipAsset`。
`StartEffect` / `EndEffect`每个飞行体的起点/终点特效 prefab。
`StartEffectDestroyTime` / `EndEffectDestroyTime`对应特效自动销毁时间，0 表示不自动销毁。
Request Details

`FlySequenceRequest` 参数和释放策略

字段说明
`Scale`本次序列整体缩放倍率，适合 UI 场景下复用同一配置但改变视觉尺寸。
`UseUnscaledTime`是否忽略全局时间缩放，适合暂停态或独立表现层。
`OnArrive`每个可视飞行体到达时回调，参数是已压缩权重后的逻辑数量增量。
`OnCompleted`所有可视飞行体结束后回调。
`VisualCountOverride`覆盖配置中的 `MaxVisualCount`，通常只在非常特定的表现需求下使用。
`DisposeMode`决定飞行体实例结束后是回收到池还是直接销毁。

`FlyInstanceDisposeMode`

枚举值说明
`RecycleToPool`默认模式，回收到对象池，适合常规高频表现。
`Destroy`直接销毁实例，不回收到池，适合一次性表现或明确不希望复用的情况。
Icon Bounce

图标回弹效果

`IconBounceEffect.Play()`

将当前节点按配置或内联参数执行一次回弹缩放动画。默认行为会以缓存的原始缩放为基准；若开启 `AllowStacking`，则允许连续触发时叠加当前状态。

关键字段说明
`Config`可选 `IconBounceConfig` 资产，为空时使用组件上的内联参数。
`Duration`回弹总时长，最小受限于 0.01 秒。
`BounceStrength`回弹强度，控制对原始缩放的偏移幅度。
`UseUnscaledTime`是否忽略 `Time.timeScale`。

`IconBounceConfig` 参数细节

字段类型作用
`Duration``float`回弹总时长，`OnValidate()` 会强制不小于 0.01 秒。
`BounceStrength``float`回弹强度，范围为 0 到 1。
`BounceCurve``AnimationCurve`定义缩放偏移曲线，`EvaluateScale(t)` 会在其基础上叠加强度。
`UseUnscaledTime``bool`是否在暂停或时间缩放场景下仍按真实时间播放。
`AllowStacking``bool`是否允许连续触发时叠加当前播放状态，而不是重置回原始缩放。

`EvaluateScale(float t)` 的含义

这个方法返回的是“缩放偏移量”，而不是最终缩放值。实际效果是先用 `BounceCurve` 在归一化时间上采样，再乘以 `BounceStrength`，最后加到基础缩放逻辑中。因此调曲线时更像是在调“偏移振幅”，而不是直接调最终缩放。

Other Effects

其他表现能力

`CameraShake`

扩展包内的相机抖动能力，适合把基础抖动参数抽离成稳定调用入口。

Editor 配套

`FlyAnimationConfigEditor`、`FlyAnimationDebugRunnerEditor`、`IconBounceConfigEditor`、`IconBounceEffectEditor` 为这些效果提供调试和预览入口。

资源与释放

飞行动画系统和资源池、Audio、对象释放策略是联动的，不建议业务自己重复管理实例生命周期。
