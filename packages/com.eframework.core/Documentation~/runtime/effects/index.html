Moved To Extension

Effects 模块迁移

Core 页保留迁移提示。飞行动画、IconBounce 和 CameraShake 的实际使用见 Effects 扩展包页面。

特点和能力

Core 状态

Core 不再承载表现效果实现，仅保留迁移入口。

扩展包

com.eframework.effects 提供 FlyAnimationSystem、IconBounceEffect、CameraShakeFx。

范例

迁移到 Effects 扩展包

  • 在初始化向导的 Extensions 中勾选 Effects。
  • 执行 Apply 写入 Packages/manifest.json。
  • 业务表现调用迁移到 EFramework.Extensions.Effects 命名空间。

API 细节

入口用途最小记忆点
com.eframework.effects表现效果 package按需安装。
FlyAnimationSystem飞行动画序列替代 Core 内旧表现入口。
IconBounceEffect / CameraShakeFx局部表现辅助由扩展包维护。
