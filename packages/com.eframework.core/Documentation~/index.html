Start Here

先选你的任务

新项目

初始化一个 EFrame 项目

用项目初始化向导复制 Basic 模板，同步 AI 工作区，补齐 Addressables、UI 层级、音频和 build settings。

UI

创建一个 UI 页面

按资源路径、生成 View、Controller 和 Show/Hide 生命周期落地，不直接操作 BindingViewBase 生命周期。

Data

接入一张 DataTable

用稳定 StorageKey、受控修改和 LastLoadResult/LastSaveResult 组织持久化数据。

Resource

梳理资源预加载

资源放进托管目录，通过 ResPath 和显式 handle 管理加载与释放。

Core Modules

核心模块

Core

启动、EFrameContext、Procedure、协程服务和上下文注入。

Assets

托管 Addressables、ResPath、异步句柄和资源释放责任。

UI

handle-first UI 主链：Controller -> Handle -> QUI -> BindingViewBase。

Data

DataTable<T>、稳定 StorageKey、dirty、迁移和结构化结果。

Audio

Music/SFX、Mixer、AudioClipAsset、池化、防抖和音乐 crossfade。

Events

结构体事件总线、Scoped 订阅和 App 生命周期广播。

Utils

输入、对象池、时间、HTTP、集合和低层辅助工具。

Extensions

可选扩展包

UI

UI Extras

把复用控件、交互反馈、图形辅助和虚拟列表从 Core 主链中拆出。

FX

Effects

承载飞行动画、图标弹跳和轻量 CameraShake，业务项目按需安装。

Debug

Debug Console

运行时日志与命令控制台，适合开发包和测试环境。

AI

AI Loop

Editor-only 截图、标注、输入模拟、录制和回放，服务 AI 辅助验收。
