AI 协作层契约

AIWorkspace 同步业务项目需要的 instructions、skills、managed blocks 和 API support docs；maintainer-only release 与 manifest 规则留在外层工具目录。

同步边界

eframe-*

框架托管并同步到业务项目，项目不应手工 fork。

project-*

业务项目本地 overlay，只写项目差异。

maintainer-*

只服务框架仓库维护，不同步到业务项目。

EFRAME_AI_API_INDEX.md

面向 AI 的稳定 API 查询入口，同步到 .github/eframe/。

何时更新 AI 层

  • 启动流程、目录结构、资源规则、UI 主链、DataTable 契约、bootstrap 工具发生变化。
  • 变更会影响 Copilot、Codex 或 Claude Code 在业务项目里的生成、重构或审查方式。
  • 发布或同步托管 AI 文件前按 maintainer release checklist 校验。
