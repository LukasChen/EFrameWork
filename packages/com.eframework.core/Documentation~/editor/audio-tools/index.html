Audio Authoring

音频编辑器工具

AudioClipAssetEditor 和 Audio Bootstrap 负责资产包装、Mixer 准备和基础资源落地。运行时仍通过 EFrame.Audio 消费。

特点和能力

AudioClipAsset

把一个或多个 clip 和播放参数包装为运行时入口。

Mixer 初始化

Audio Bootstrap 准备基础 mixer 和资源路径。

运行时消费

业务通过 EFrame.Audio 播放，不直接依赖 Editor 配置。

范例

创建一个 AudioClipAsset

  • 完成 Audio Bootstrap。
  • 创建或选择 AudioClipAsset。
  • 配置 clips、volume、pitch、min interval。
  • 运行时用 PlayAudioClipAsset 或 PlaySfx。

API 细节

入口用途最小记忆点
AudioClipAssetEditor维护音频片段集合和播放参数适合 UI 音效、随机短音频。
Audio BootstrapMixer 和基础资源准备项目初始化会处理。
AudioResourcePaths框架音频资源路径Resources 侧入口。
