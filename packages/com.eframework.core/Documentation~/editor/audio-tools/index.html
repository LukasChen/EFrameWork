Audio Authoring

Audio 编辑器工具负责把事件、配置资产和资源组织成可维护的音频工作流。

当前核心能力包括 `AudioEventEditorWindow`、`AudioClipAssetEditor` 和 `AudioEventConfigCreator`。重点不是单次预览，而是为所有 `IEvent` 事件建立可配置的音效和震动映射。

主窗口
`AudioEventEditorWindow`
配置资产
`AudioEventConfigAsset`
资源入口
`AudioResourcePaths`
Main Tool

`AudioEventEditorWindow` 工作流

扫描事件类型

窗口在 `OnEnable()` 时扫描所有实现 `IEvent` 的结构体，整理成可筛选事件列表。

按命名空间和关键字过滤

支持按命名空间、搜索词和“仅看已配置事件”筛选，适合大型项目逐步补音频事件。

配置音效与震动

为事件配置音频组、条件、顺序播放、权重、震动模式等逻辑，并保存到统一资产里。

预览与保存

窗口内部维护预览 `AudioSource`，并在禁用或关闭时保存配置资产。

Recommended Usage

推荐工作流

  1. 先确保项目已经完成 Audio Bootstrap，资源路径和配置资产已经就位。
  2. 打开 `Audio Event Editor`，从事件列表选择目标 `IEvent`。
  3. 为该事件配置音效片段、播放策略、条件和震动。
  4. 使用预览能力验证结果，再保存到统一 `AudioEventConfigAsset`。
  5. 运行时让 `AudioEventManager` 消费这份配置，而不是在业务代码里散写音效分支。
Related Tools

相关 Editor 能力

`AudioClipAssetEditor`

用于维护 `AudioClipAsset`，把一个或多个音频片段整理成运行时可消费的资产入口。

`AudioEventConfigCreator`

提供配置资产创建入口，避免手工建错路径或类型。

Bootstrap 协作

Audio Tools 不是孤立的。它依赖 Bootstrap 先把 Mixer、Resources 路径和默认配置资产准备好。
