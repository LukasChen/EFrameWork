Audio Authoring

Audio 编辑器工具负责把基础音频资产组织成可维护的音频工作流。

当前核心能力保留 `AudioClipAssetEditor` 和 Audio Setup；事件式音频映射与触觉反馈不再属于 core。

Main Tool

`AudioClipAsset` 工作流

整理音频片段

`AudioClipAsset` 可以把一个或多个音频片段包装成运行时播放入口。

配置随机参数

音量、音调和最小播放间隔由资产维护，运行时通过 `EFrame.Audio` 消费。

Bootstrap Mixer

Audio Setup 和项目初始化向导负责创建 `EFrameAudioMixerSettings.mixer`。

运行时播放

`AudioManager` 负责 Music/SFX、Mixer 音量、SFX 池、防抖和音乐 crossfade。

Recommended Usage

推荐工作流

  1. 先确保项目已经完成 Audio Bootstrap，Mixer 资源已经就位。
  2. 为常用 SFX 创建 `AudioClipAsset`。
  3. 在资产上配置音频片段、随机音量/音调和最小播放间隔。
  4. 运行时通过 `EFrame.Audio.PlayAudioClipAsset(...)` 或 `EFrame.Audio.PlaySfx(...)` 播放。
Related Tools

相关 Editor 能力

`AudioClipAssetEditor`

用于维护 `AudioClipAsset`，把一个或多个音频片段整理成运行时可消费的资产入口。

Bootstrap 协作
