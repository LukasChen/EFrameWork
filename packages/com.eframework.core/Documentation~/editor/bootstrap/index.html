Project Bootstrap

Bootstrap 初始化工具

项目初始化向导负责 Basic、扩展包、Showcase、Addressables、Audio、DOTween Adapter、StartUp 和 build settings。模板复制由该工具统一执行。

特点和能力

Basic 模板

创建 StartUp 场景、Procedure、Home UI、音频资源和基础目录。

资源同步

修复托管 Addressables entries，并生成 ResPath。

扩展安装

按 Core 来源写入本地 file 或 git package 依赖。

Showcase 模块

安装可选扩展示范模块并设置 StartUp 入口。

范例

新项目 / 修复项目

  • 打开 EFrame Tools/项目初始化向导。
  • 先执行 Initialize / Repair Project。
  • 再按需勾选 Extensions 并 Apply。
  • 需要扩展示范时安装 Showcase。

API 细节

入口用途最小记忆点
Initialize / Repair Project复制 Basic 并修复项目结构首选冷启动入口。
Extensions -> Apply写入可选 package 依赖和 DOTween define取消勾选不删除已安装包。
Showcase -> Install Showcase安装扩展示范模块依赖导入完成后可重复点击修复。
Addressables Sync托管目录和 ResPathbuild 前会 preflight。
