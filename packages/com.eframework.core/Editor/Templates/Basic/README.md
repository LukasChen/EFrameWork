# EFrame Basic Template

This directory is the machine-readable source for the Basic initialization template. The Unity initialization window and bootstrap scripts generate the same structure in consuming projects.

Keep this template aligned with:

- `Tools~/Initialize-EFrameBootstrapCode.ps1`
- `tools/Initialize-EFrameBootstrapCode.ps1`
- `Samples~/Basic/README.md`

Basic must remain minimal and must not reference optional extension packages.
