# EFrame Basic Template

This directory is the package copy of the Basic initialization template. The Unity initialization window and bootstrap scripts copy this structure into consuming projects.

Keep this template aligned with:

- `test-fixtures/EFrameBasicTemplate/Assets`
- `tools/Sync-EFrameBasicTemplate.ps1`
- `Tools~/Initialize-EFrameBootstrapCode.ps1`
- `tools/Initialize-EFrameBootstrapCode.ps1`

Basic must remain minimal and must not reference optional extension packages.
